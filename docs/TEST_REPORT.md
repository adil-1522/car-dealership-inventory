## What the tests cover

**Security**

- Passwords are stored bcrypt-hashed, never in plain text, and never returned by the API
- Registration cannot assign the admin role to itself
- Unknown email and wrong password return the same 401 message
- Forged, expired and non-Bearer tokens are all rejected
- Every write route returns 403 for a regular user's token
- Internal errors return a generic 500 with no stack trace or SQL

**Correctness**

- Six concurrent purchases against three units: exactly three succeed, final stock is zero
- Purchasing more than the stock leaves the quantity unchanged (409)
- Partial `PUT` updates leave the other fields untouched
- Search combines filters with AND, is case-insensitive, and treats `%` literally
- `minPrice > maxPrice` is rejected with 400

**User experience**

- Purchase buttons are disabled when sold out and while a request is in flight
- Admin controls are absent from the DOM for regular users
- Route guards redirect guests to login and signed-in users away from login
- Server error messages are surfaced in the UI rather than swallowed
